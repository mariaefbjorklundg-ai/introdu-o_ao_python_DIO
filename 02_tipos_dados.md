## Tipos
Servem para definir a característica/comportamento de um valor

### Tipos Buil-in = int()

| Tipos | Descrição |
| --- | --- |
| Texto | str |
| Número | int, float, complex |
| Sequência | list, tuple, range |
| Mapa | dict |
| Coleção (Conjunto) | set, frozenset |
| Booleano | bool (True ou False, subclasse de int) |
| Binário | bytes, bytearray, memoryview |

#### Números Inteiros
São representados pela clase **int** e possuem precisão ilimitada

Exemplo: 1, -1, 5049, -3840

#### Números de Ponto Flutuante
Os Números de Ponto Flutuante são usados para representar os números racionais e sua implementação é feita pela classe **float**

Exemplos: 1.5, -1087.977, 0.76


### Tipo Booleano
É usado para representar Verdadeiro ou Falso, é implementado pela classe **bool**.

No Python o tipo Booleano é uma subclsse de **int**, sendo assim qualquer número diferente que 0 representará Verdadeiro e 0 representará Falso 

Exemplos: True e False

### Strings
Strings ou Cadeia de caracteres é usada para representar valores alfanúmericos.

São utilizadas a classe **str**.

 Exemplos: "Python", 'Python', """Python""", '''Python'''


 ## Exemplo em Python

 ```Python

 print(20 + 68 + 68)
 >>> 156

print(1.5 + 5 + 0.5)
>>> 7.0

print(True)
>>> True

print(False)
>>> False

print("Python")
>>> Python
``
