## Operadores de Compenção 
São utilizados como operadores para comparar dois valores

* Igualdade
```Python
saldo = 550
saque = 300

print(saldo == saque)# quero ver se o saldo é igual ao saque
>>> False # pois é diferente o valor do saque e do saldo
```

* Diferença
```Python
saldo = 550
saque = 300

print(saldo != saque) # agora queremos saber se saldo é diferente de saque
>>> True #sim, é diferente
```

* Maior que / maior ou igual
```Python
saldo = 550
saque = 300

printe(saldo > saque) #saldo é maior que saque
>>> True

print(saldo >= saque) #saldo é maior ou igual a saque
>>> True
```

* Menor que / menor ou igual
```Python
saldo = 550
saque = 300

print(saldo < saque) #saldo é menor que o saque
>>> Falso #não

print(saldo <= saque) #saldo é menor ou igual a saque
>>> Falso
