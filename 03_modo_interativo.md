## Modo Interativo 🎴
A pessoa que esta utilizando o Python pode usar em modo que possibilite o desenvolvedor a escrever o código, e ver o resultado na hora

*  Para Iniciar tem duas formas : Chamando o interpretador (Python);

  ou

  Executando o script com flag -i (Python -i app.py)

  ### Funções

  * Dir

Sem argumentos, retorna a lista de nomes no escopo local atual.

Com um argumento, retorna uma lista de atributos válidos para o objeto.

Exemplo: dir()
         dir(100)

* Help

Invoca o sistema de ajuda integrado.

Pode fazer buscas em modo interativo ou informar por parâmetro qual o nome do módulo, função, classe, método ou variável.

Exemplo: help ()
         help(100)
