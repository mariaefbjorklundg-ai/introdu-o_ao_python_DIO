## Operadores de Atribuição
São utilizados para operar aonde definem o valor inicial ou sobrescrever o valor de uma variável.

* Atribuição Simples
```Python
saldo = 600
#atribui um valor a uma variavel

print(saldo)
>>> 600
```
* Atribuição com Adição
```Python
saldo = 600
saldo += 300 # adiciona esse valor ao saldo

print(saldo)
>>> 900
```
* Atribuição com Subtração
```Python
saldo = 600
saldo -= 300

print(saldo)
>>> 300
```
* Atribuição com Multiplicação
```Python
saldo = 600
saldo *= 2

print(saldo)
>>> 1200
```
* Atribuição com Divisão e Divisão Inteira
```Python
saldo = 600
saldo /= 5

print(saldo)
>>> 120.0

saldo = 600
saldo //= 5

print(saldo)
>> 120
```
* Atribuição com Módulo
```Python
saldo = 600
saldo %= 250

print(saldo)
>>> 100
```
* Atribuição com Expoenciação
```Python
saldo = 600
saldo **= 2

print(saldo)
>>> 360000
